# Pizza Sales Analysis using SQL

## Project Overview
This project analyzes pizza sales data using SQL to uncover business insights related to revenue, customer orders, and product performance.

## Objectives
- Calculate total revenue generated from pizza sales
- Identify top-selling pizzas
- Analyze sales performance by category and size
- Determine peak ordering periods
- Understand customer purchasing patterns

## Tools Used
- MySQL
- SQL
- GitHub

## Database Tables
- orders
- orders_details
- pizzas
- pizza_types

## SQL Concepts Used
- Database and Table Creation
- Joins (INNER JOIN)
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY
- ORDER BY
- WHERE Clause
- HAVING Clause
- Subqueries

## Key Insights
- Identified the top-performing pizza categories.
- Determined the pizzas generating the highest revenue.
- Analyzed customer ordering behavior and peak sales hours.
- Provided data-driven insights to support business decisions.
